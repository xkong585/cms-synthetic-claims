# CMS 合成住院理赔项目：已完成内容

使用官方 DE-SynPUF Sample 1，保留 116,352 名合成受益人的完整台账。按理赔结束日
CLM_THRU_DT 归属 2008 年，不把三年记录误称为 2008 年，也不把 claim 等同独立住院。

实际发现 67 笔多 segment 理赔的字段冲突，全部隔离；其中 21 笔影响 2008 年的
21 名受益人。完整台账仍保留这些人，但完整年度金额与理赔数为空，不误填零。
主分析为 116,331 人、27,449 笔一致理赔；其中 100,607 人确实没有符合条件的理赔。
全部已接受的 2008 年理赔为 27,475 笔，这与排除受影响受益人后的主分析口径不同。

重点发现：官方年度报销定义包含“支付额 + 覆盖天数 × pass-through 日额”。对可核对
的 116,331 人，该公式与源表精确到分一致；直接相加 CLM_PMT_AMT 会少 2,733,780
合成美元。此处不是现实医疗成本或节省金额。

交付包括代码、Python/DuckDB/SQLite 对账、25 项测试、16 项独立数值核对、数据字典、
隔离与日期规则、覆盖月份敏感性分析、可切换人群的 HTML 报告、两页英文 PDF 简报、
运行与复现证据，以及经核实的简历表述和面试说明。

复跑方法见英文 README。仓库不放原始数据或个人级派生明细；一键脚本会从官方来源
下载并核对 SHA256。数据完全合成，仅证明数据处理与软件流程能力。

## ML 补充

新增用 2008 年特征预测 2009 年是否有住院理赔的 ML 模块。73,757 名合成受益人满足完整随访要求；严格分开训练、校准和测试。测试 AP 从基线 0.1749 提升到梯度提升的 0.2711，AUC 为 0.6155。校准后 Brier 没有改善，报告保留原始结果。只支持合成数据方法演示，不代表真实患者表现。

打开 `reports/ml_report.html` 查看模型比较、变量重要性、分组误差及校准图（CMS）；`reports/ml_brief.pdf` 是一页英文摘要。仍使用原来的一键命令运行全部分析和测试。
